独立存放规则

plugins/
└─ flstrengthen/
   ├─ index.html
   ├─ styles.css
   └─ app.js

每个项目使用自己的目录和静态资源。以后新增插件时，只在 plugins/ 下增加子目录，不会影响已有文档。

部署方式

全站为纯静态 HTML、CSS 和 JavaScript，由 GitHub Pages 托管，不依赖后端服务或外部 CDN。
